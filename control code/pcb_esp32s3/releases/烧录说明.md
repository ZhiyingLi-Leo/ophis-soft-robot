# ESP32-S3首次烧录文件

目标：PCB1/Y2，ESP32-S3-WROOM-1-N8，8MB Flash、无PSRAM。

| 文件 | 写入地址 |
|---|---|
| `propulsion_pcb_full.bin` | 0x0，已包含以下各部分，首次烧录优先使用 |
| `bootloader.bin` | 0x0 |
| `partitions.bin` | 0x8000 |
| `boot_app0.bin` | 0xe000 |
| `firmware.bin` | 0x10000，仅应用程序 |

整包与分文件二选一，不必重复写入。参数：ESP32-S3、DIO、80MHz、8MB。正常方式推荐从firmware目录执行PlatformIO上传，工具会选择正确分区文件。

需要命令行整包烧录时，安装esptool 4.9.0后，在本目录执行：

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem实际端口 --baud 460800 write_flash 0x0 propulsion_pcb_full.bin
```

首次按BOOT/RESET进入下载模式；只接Type-C，先不接24V电机电源。烧录完成后按RESET启动，端口可能重新枚举，重新选择新端口。该步骤尚待真实样板验证。这里没有程序烧录或电机启动自动化任务。
