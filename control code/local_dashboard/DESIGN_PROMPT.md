# 科研控制工作站设计提示词

为一套三通道液压软体导管机器人实现本地科研控制工作站。目标用户在实验台前观察设备状态、逐轴调节位移、检查通信与记录实验；界面应有精密仪器软件的克制、秩序和可读性。

## 布局与视觉

- 使用冷白、浅灰、石墨文字；单一深蓝作为操作色，蓝/青/赭黄区分三个液压通道。红色仅用于停止与故障。
- 不使用营销标题、口号、奶油绿背景、夸张圆角、浮夸渐变或无意义指标。
- 顶部是工作站名称、固定的真实硬件标识、本地服务状态和可随时触达的全部停止。
- 左侧是设备拓扑和串口接入。中央是大面积真实CAD装配视图，右上提供总览、液压组件、推进组件、俯视、复位等可用视角。
- 总览仅放装配状态与模块摘要；液压、推进、相机使用独立工作区，不堆叠在一页。液压工作区的三张对齐通道面板分别呈现ID、反馈位置、目标位置、限位、速度、温度与通信年龄；数值等宽、单位明确，连接/启用/运动状态分别可辨。
- 收起非主操作信息，用清晰的分区和细边线组织三轴协同、推进控制及事件日志。宽屏优先，窄屏完整重排，不横向溢出。

## 三维呈现

- 直接加载 `3d model/Triple_Cylinder_Syringes_V3.glb` 与 `3d model/Advancer_Assembly.glb`，不覆盖或重新导出源模型。
- 参考给定示意图：三通道注射器驱动在左，滚轮推进组件在中，导管在右。三条蓝/青/赭黄液路连到导管。
- 使用WebGL、透视/正交工程视角、柔和环境照明、金属与半透明注射器材质。地面仅作定位，不使用密集网格抢占视觉。
- 真实CAD保持原有尺寸关系；部件标签与引线清楚。可旋转、缩放、平移、选择通道，具有视角预设。
- 滑块与推杆随电缸反馈作位移示意；模型通道号及运动方向需要现场确认。离线时不伪造反馈或显示运动。
- 导管弯曲与气道只能明确标记为结构示意。未接相机、未标定时，不能假称三维形状、角度或压力是实测值。
- 模型加载失败与WebGL不可用时给出可读提示，不允许空白视图或阻断控制面板。

## 控制行为

- 仅提供真机操作；启动不扫描/连接设备，不自动回零。离线模拟仅用于内部自动测试。
- 各电缸和推进器独立接入；三轴协同仅在参与轴全部就绪时可用。
- 保留目标校验、停止、心跳失效、串口独占、单控制会话和故障处理。
- 四电机读取 PCB STATUS；展示板端脉冲频率及驱动电流设定，明确不是实测转速或电流。Nano 不支持四路遥测时显示不支持。D405独立预留，明确显示“未实现采集”，不生成虚假画面。
- 禁止按钮装饰化：每个按钮都执行标注的动作；状态必须取自后端。

## 验收

检查真实GLB加载、比例与朝向、零件材质、模型视角切换、通道选择、真机默认断开、毫米状态标签、四路状态解析、停止、三轴整体校验、窄屏重排以及浏览器错误日志。所有验证使用模拟或虚拟串口，不操作实物。
